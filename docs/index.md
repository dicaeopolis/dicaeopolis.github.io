# 欢迎来到Dicaeopolis' Wiki

## 关于本 Wiki

本Wiki旨在提供一个交流技术和知识的平台。

说是 Wiki，其实是个人博客。但我不喜欢时间线一般的博客组织方式。在我的生命中，有无数的兴趣点沉沉浮浮，若用时间顺序组织，反倒更杂乱。

## 关于作者

作者目前主要研究深度伪造音频的反欺诈问题，并对研究过程中产生的其他问题保持开放。同时，作者也不得不应付来自学业 GPA 和各项冗杂事务等的压力，并需要和风车搏斗。

在 2026 年上半年，作者深感前沿 LLM 对知识分享的冲击之甚，加之课业比赛事务繁忙，遂停更博客。但经过半年的使用与思索，作者发现**个人鲜活的知识和经验是千篇一律的 LLM 生成文本所无法取代的**，而这给予作者维持更新的动力。
